# SSH-Bruteforce-Detection

## Overview

This project simulates an SSH brute-force attack against a Linux server and detects suspicious login activity using Python.

## Tools

- Ubuntu Server
- Python
- Hydra
- VirtualBox

## Detection Logic

- Count failed login attempts
- Track successful logins
- Flag suspicious IP addresses
- Generate CSV reports

## Results

Detected:
- Failed login attempts
- Successful logins after brute-force attacks
- Risk level assessment
